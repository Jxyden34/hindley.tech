Personal operating-system project · In development

Cosmopod OS

A Linux distribution project for Raspberry Pi 4, Raspberry Pi 5 and x86-64 virtual machines.

LinuxYoctosystemdWayland / WestonMenderBash

Scope: Defines board-specific Linux images, a Wayland desktop and signed A/B update and recovery tooling; full release qualification remains in progress.

The problem

A small Linux system needs a repeatable build, a usable desktop, secure administration and an update path that accounts for different hardware and recovery requirements.

What I built

I develop a Yocto-based distribution with separate Raspberry Pi and x86-64 boot targets, a Wayland desktop, hardened SSH configuration and signed A/B update tooling for Raspberry Pi.

Outcome and limits

The public repository defines separate image outputs, update health checks, integrity metadata and qualification requirements for each target. Full release qualification remains in progress.

What I would improve next

I would complete and publish the remaining hardware, boot, desktop, SSH, update and standalone recovery checks for each target before describing a release as fully qualified.
