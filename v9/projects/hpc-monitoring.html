HPC Monitoring Dashboard

Lab availability, login activity and uptime in one shared Python and Flask dashboard.

PythonFlaskMonitoring

Scope: Brings machine status, uptime and login activity into a shared view for a university lab environment.

The problem

Checking lab and HPC machines separately makes availability and login activity harder to follow across the environment.

What I built

I built a Python and Flask application that pings lab machines, parses login logs and presents machine status and uptime in one web dashboard.

Outcome and limits

The dashboard is listed as in use at the university. It gives the team a shared view of machine status and activity instead of requiring separate checks for each host.

What I would improve next

I would record the number of monitored machines and compare a timed manual status check with the dashboard workflow. I would also document how stale or unreachable hosts are shown.
