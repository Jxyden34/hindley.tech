Monitoring & automation

HPC Monitoring Dashboard

A Flask dashboard that brings lab-machine availability, login activity and uptime into one view.

PythonFlaskMonitoring

The problem

Lab and HPC environments involve many machines. Checking availability and login activity individually makes it harder to see which systems need attention.

What I built

I built a lightweight Python and Flask application that pings lab machines, parses login logs, and presents live status and uptime information in a web dashboard.

What it enables

The dashboard provides a shared view of machine status and is used in a university environment. It makes the monitoring information available in one place.
