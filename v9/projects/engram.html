Personal software project · Self-hosted memory and AI context

Engram

A self-hosted platform that brings documents, source-aware retrieval and AI context into one system.

PythonNext.jsPostgreSQL / pgvectorDocker ComposeOllamaMCP

Scope: Connects document ingestion, source-aware search, local AI processing and scoped MCP access in a self-hosted platform.

The problem

Documents, saved pages and conversations leave useful context scattered across separate tools. Finding a fact is more useful when its source and access boundaries remain visible.

What I built

I develop Engram as a self-hosted platform with document ingestion, a review workflow, PostgreSQL and pgvector retrieval, a Next.js interface, local Ollama processing and REST/MCP integrations.

Outcome and limits

The public repository documents ingestion, hybrid retrieval, source provenance, project-scoped access and backup/restore tooling. Its code and documentation make the implementation available to inspect.

What I would improve next

I would publish a small reproducible walkthrough from source upload to reviewed memory, retrieval and restore verification, with a clearly bounded evaluation dataset.
