Server management & automation

iDRAC Telegram Bot

Dell server status, history and safe power actions through a Telegram bot.

PythonRedfishiDRAC

The problem

Managing physical servers sometimes requires access outside the operating system. Checking health and taking power actions should be available from a convenient interface.

What I built

I integrated Dell iDRAC with a Python Telegram bot using Redfish APIs, bringing server status, graphs, history and safe power actions into chat.

What it enables

The bot brings out-of-band server management into the same interface as status information. This project remains ongoing as the management workflow develops.
